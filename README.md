# Isobek Sharipov - Single Page Portfolio

IBM Final Project: Submission and Evaluation.

A responsive portfolio built with HTML5, CSS3, and JavaScript, featuring:
- Name and navigation bar
- About Me
- Skills
- Projects
- Recommendations with an interactive submission form
- A working floating Home icon

## Run
Open `index.html` in any modern browser. No dependencies or build commands are needed.

## Files
- `index.html`: structure and accessible page sections
- `style.css`: responsive styles
- `script.js`: recommendation interaction and popup

The initial recommendations are clearly marked as portfolio samples, not real testimonials.
